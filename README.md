# leyla.sda — Personal Brand Operating System

این مخزن، اتاق فرمان برند شخصی `leyla.sda` است: ایده‌پردازی، تحقیق، تقویم محتوا، agentها، تصمیم‌ها، آزمایش‌ها و گزارش‌ها.

## هدف فعلی
حرکت از یک پیج قدیمی با محور روانشناسی/خودمراقبتی/خودشناسی/ارتباطات به یک برند شخصی چندموضوعی و انسانی؛ با سه زبان فارسی، انگلیسی و ترکی و با حضور طبیعی در موضوعاتی مثل کار و تجربهٔ روزمره، استفادهٔ کاربردی از هوش مصنوعی، خودشناسی و ارتباطات، تجربهٔ محصول و آموزش، و نظر شخصی.

## اصل اجرایی
هر خروجی باید در یکی از این مسیرها ذخیره شود:

- `docs/`: تصمیم‌ها، جایگاه برند، قوانین
- `agents/`: نقش‌ها و قرارداد agentها
- `research/`: تحقیق و تحلیل منابع
- `content/`: ایده‌ها، اسکریپت‌ها، کپشن‌ها و تقویم
- `ops/`: گردش‌کار، وضعیت انتشار و تحویل‌ها

## وضعیت دسترسی‌ها

- رپو هدف: https://github.com/leylasaadati99-ux/instagram
- ارسال تلگرام: در انتظار bot token و chat_id
- بررسی اینستاگرام: فقط منابع عمومی وب
- Git/Chrome در محیط فعلی متصل نیستند؛ فایل‌ها برای commit آماده‌اند.

## نحوهٔ کار برای مدل‌های بعدی
ترتیب canonical خواندن: `AGENTS.md` ← `README.md` ← `docs/brand-brief.md` ← `docs/operating-rules.md` ← آخرین `research/` ← `CHANGELOG.md`. از تکرار تحقیق‌های موجود خودداری کن و هر تصمیم جدید را در `docs/decisions/` ثبت کن.
