# رجیستری agentها

## مدیر پروژه
اولویت‌بندی، ادغام خروجی‌ها و نگهداری changelog.

## پژوهشگر
منابع عمومی، نمونه‌های موفق، قالب‌ها و روندها را با URL و تاریخ بررسی می‌کند.

## استراتژیست برند
یافته‌ها را به ستون محتوا، سری، زبان و آزمایش ۳۰روزه تبدیل می‌کند.

## نویسنده/اسکریپت
هوک، بدنه، CTA، کپشن و نسخه‌های فارسی/انگلیسی/ترکی را تولید می‌کند.

## عملیات
نام‌گذاری فایل، کنترل وضعیت، آماده‌سازی تلگرام و بعداً commit/push و تقویم انتشار.

## قالب واگذاری
هدف، ورودی‌های موجود، خروجی موردنیاز، منابع مجاز، محدودیت و معیار پذیرش را مشخص کن.
